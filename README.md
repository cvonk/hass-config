# Home Assistant Configuration

##  A few words to the wise

- Use the Visual Code addon in Home Assistant, and embrase the folding editor.

- However tempting, I didn't split up this file, because it caused problems
  with !include files staying cached.

- Some credentials must reside in secrets.yaml what is not included in this
  repository

- Remember, browser_mod can be used to print values on the console of the
  browser.

- Many thanks to Mattias Persson for sharing his work.  It gave me a head
  start in configuring this Dashboard
